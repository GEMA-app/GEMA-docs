# Propuesta de modelo de datos

Este documento presenta un propuesta del esquema de base de datos de GEMA en revisión. Recoge todas las mejoras identificadas sobre el modelo y las consolida en un esquema unificado.

> [!IMPORTANT]
> Esta propuesta está en revisión. Los cambios incluyen: soporte multimoneda con histórico de tasas, auditoría granular por campo, eliminación de redundancia en planes preventivos, firmas digitales en órdenes de trabajo, enums para integridad de datos y un módulo de BI con KPIs y alertas.

---

## Enums del sistema

Esta propuesta agrega enums nuevos y renombra algunos existentes para mayor consistencia.

| Enum | Valores | Cambio respecto a v0 |
|---|---|---|
| `estado_activo` | `operativo`, `mantenimiento`, `fuera_servicio`, `baja` | Sin cambios |
| `estado_orden_trabajo` | `abierta`, `en_progreso`, `en_espera_repuesto`, `completada`, `cancelada` | Renombrado de `estado_ot` |
| `tipo_mantenimiento` | `preventivo`, `correctivo`, `predictivo` | Sin cambios |
| `nivel_prioridad` | `critica`, `alta`, `media`, `baja` | Renombrado de `prioridad_nivel` |
| `tipo_ubicacion` | `sede`, `planta`, `area`, `seccion` | Nuevo |
| `modulo_permiso` | `activos`, `ot`, `inventario`, `reportes`, `admin` | Nuevo |
| `tipo_alerta` | `stock_bajo`, `vencimiento_plan`, `otra` | Nuevo |
| `estado_alerta` | `pendiente`, `resuelta`, `archivada` | Nuevo |

El enum `frecuencia_tipo` se elimina. Su función la cubre `intervalo_dias` como fuente única de verdad.

## Cambios respecto a v0

| Categoría | Detalle |
|---|---|
| Enums nuevos | `tipo_ubicacion`, `modulo_permiso`, `tipo_alerta`, `estado_alerta` |
| Enums renombrados | `estado_ot` → `estado_orden_trabajo`, `prioridad_nivel` → `nivel_prioridad` |
| Enums eliminados | `frecuencia_tipo` (reemplazado por `intervalo_dias` not null) |
| Tablas nuevas | `configuraciones_sistema`, `tasas_cambio`, `planes_ejecuciones`, `logs_estados_ordenes_trabajo`, `auditorias_cambios`, `alertas`, `kpis_activos_mensuales`, `kpis_tecnicos_mensuales` |
| Tablas renombradas | `auditoria_sistema` → `auditorias_sistema`, `ot_tecnicos_asignados` → `ordenes_trabajo_tecnicos_asignados`, `reportes_falla` → `reportes_fallas` |
| Patrón multimoneda | `activos`, `ordenes_trabajo`, `inventario_repuestos`, `entradas_inventario` |
| Firma digital | `validado_gerencia` → `validado_por_id` + `fecha_validacion` |
| Integridad | Campos `text` → `varchar` o enums nativos en todas las tablas |
| Timestamps | Todas las tablas ganan `created_at` y `updated_at` con `default: now()` |
