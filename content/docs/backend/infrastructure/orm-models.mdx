Los modelos ORM son las clases que representan tablas de la base de datos.
Heredan de `Base` (declarada en `db/base.py`) y usan `Mapped` + `mapped_column`
de SQLAlchemy 2.0.

Todos los modelos viven en el paquete `src/app/infrastructure/db/models/`.

## Mixins Reutilizables

Para evitar la duplicación de código en un sistema multi-tenant, se implementan mixins en `src/app/infrastructure/db/models/mixins.py`:

```python
class TenantMixin:
    """Mixin que agrega empresa_id con FK e índice a cualquier modelo multi-tenant."""
    empresa_id: Mapped[uuid.UUID] = mapped_column(
        ForeignKey("empresas.id", ondelete="CASCADE"), nullable=False, index=True
    )

class TimestampMixin:
    """Mixin que agrega created_at y updated_at con timezone awareness."""
    created_at: Mapped[datetime] = mapped_column(
        DateTime(timezone=True), default=lambda: datetime.now(UTC), nullable=False
    )
    updated_at: Mapped[datetime] = mapped_column(
        DateTime(timezone=True),
        default=lambda: datetime.now(UTC),
        onupdate=lambda: datetime.now(UTC),
        nullable=False,
    )
```

## Ejemplo: `AssetModel`

Definido en `src/app/infrastructure/db/models/asset.py`:

```python
class AssetModel(Base, TenantMixin, TimestampMixin):
    """Modelo ORM para la tabla de activos físicos."""

    __tablename__ = "activos"

    id: Mapped[uuid.UUID] = mapped_column(primary_key=True, default=uuid.uuid4)
    articulo_id: Mapped[uuid.UUID] = mapped_column(ForeignKey("articulos_catalogo.id"), nullable=False)
    ubicacion_id: Mapped[uuid.UUID] = mapped_column(ForeignKey("ubicaciones.id", ondelete="SET NULL"), nullable=True)
    serial_interno: Mapped[str] = mapped_column(nullable=False)
    codigo_activo: Mapped[str] = mapped_column(nullable=False)
    estado: Mapped[str] = mapped_column(nullable=False)
    fecha_adquisicion: Mapped[date] = mapped_column(nullable=True)
    valor_monetario: Mapped[float] = mapped_column(nullable=True)
    moneda: Mapped[str] = mapped_column(default="USD", nullable=False)

    # Relaciones
    ubicacion = relationship("LocationModel", back_populates="activos")
```

### ¿Por qué no se usa el modelo como entidad?

El modelo ORM (`AssetModel`) es solo para la persistencia. La entidad de dominio (`Asset`) es pura y no tiene acoplamiento con SQLAlchemy. La traducción de modelo a entidad (y viceversa) se realiza mediante los repositorios (ver [Repositorios](./repositories)).

```
AssetModel (SQLAlchemy)  →  AssetRepositoryPort  →  Asset (entidad dominio)
         ↑                            ↓
   Tabla "activos"         SqlAlchemyAssetRepository
```

## Convenciones del Proyecto

- Los nombres de tablas son en plural y en español (ej. `usuarios`, `empresas`, `activos`).
- Todas las PKs y FKs usan UUIDs para consistencia del sistema.
- El aislamiento de datos se garantiza en todas las consultas utilizando el filtro `empresa_id` (proveniente del `TenantMixin`).
