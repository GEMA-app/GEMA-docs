Los repositorios implementan los puertos definidos en `application/ports/`
y traducen entre entidades de dominio y modelos ORM.

## Repositorio Base Genérico: `SqlAlchemyRepository`

Archivo: `src/app/infrastructure/repositories/base.py`

Para evitar escribir repetidamente métodos CRUD básicos (`save`, `get_by_id`, `delete`), se implementa una clase abstracta genérica:

```python
class SqlAlchemyRepository(Generic[ModelT, EntityT, IdT], ABC):
    """Repositorio base con operaciones CRUD genéricas utilizando SQLAlchemy 2.0."""

    def __init__(self, session: AsyncSession, model_class: type[ModelT]) -> None:
        self.session = session
        self.model_class = model_class

    @abstractmethod
    def _to_model(self, entity: EntityT) -> ModelT: ...

    @abstractmethod
    def _to_entity(self, model: ModelT) -> EntityT: ...

    async def save(self, entity: EntityT) -> None:
        model = self._to_model(entity)
        await self.session.merge(model)

    async def get_by_id(self, id: IdT) -> EntityT | None:
        id_val = id.value if hasattr(id, "value") else id
        stmt = select(self.model_class).where(self.model_class.id == id_val)
        result = await self.session.execute(stmt)
        model = result.scalar_one_or_none()
        if not model: return None
        return self._to_entity(model)

    async def delete(self, id: IdT) -> None:
        id_val = id.value if hasattr(id, "value") else id
        stmt = delete(self.model_class).where(self.model_class.id == id_val)
        await self.session.execute(stmt)
```

## Repositorios Implementados

Todos viven en `src/app/infrastructure/repositories/`.

### 1. `SqlAlchemyUserRepository`
Hereda de `SqlAlchemyRepository` e implementa `UserRepositoryPort`.
- Mapea el nuevo `empresa_id` y los roles asociados de un usuario.
- Añade el método `get_by_email_and_company(email, empresa_id)`.

### 2. `SqlAlchemyCompanyRepository`
Implementa `CompanyRepositoryPort`.
- Añade el método `get_by_slug(slug)` y listado paginado global para administración.

### 3. `SqlAlchemyRoleRepository`
Implementa `RoleRepositoryPort`.
- Permite asignar/revocar roles de usuarios operando sobre la tabla asociativa `roles_usuarios`.
- Carga los permisos embebidos de manera eager para optimizar el chequeo de RBAC.

### 4. `SqlAlchemyAssetRepository`
Implementa `AssetRepositoryPort`.
- Realiza consultas filtradas por `empresa_id`, `estado`, e `ubicacion_id` con paginación integrada.

### 5. `SqlAlchemyLocationRepository` (CTE Recursiva)
Implementa `LocationRepositoryPort`.
Para obtener el árbol jerárquico completo en una sola consulta de base de datos sin sobrecargar la memoria de la aplicación, el repositorio implementa una **CTE (Common Table Expression) recursiva**:


<Callout type="warn">

El repositorio **nunca** hace `session.commit()`. Solo usa `session.add()` o `session.merge()`. El commit es responsabilidad exclusiva del Unit of Work. Si un repositorio hiciera commit, rompería la frontera transaccional.

</Callout>
